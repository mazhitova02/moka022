9. Как ПРАВИЛЬНО проверять эффект (нужны сырые данные 101 ученика)
  Файл data.csv со столбцами: id, group (exp/ctl), school (A/B), pre, post
  import pandas as pd, statsmodels.formula.api as smf
  df = pd.read_csv('data.csv')
  # 1) ANCOVA: эффект метода на post при учёте pre и школы
  m = smf.ols('post ~ pre + C(group) + C(school)', data=df).fit(); print(m.summary())
  # 2) или t-тест по приросту (gain = post - pre) между exp и ctl
  df['gain'] = df.post - df.pre
  print(stats.ttest_ind(df.gain[df.group=='exp'], df.gain[df.group=='ctl'], equal_var=False))
  # 3) парный t-тест внутри каждой группы — только как дополнение
